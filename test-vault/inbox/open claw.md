# open claw

https://youtu.be/7tM7XseKJPI?si=OCcSoKhv-AsNu3yB

Este video presenta **OpenClaw 2.0**, una plataforma de inteligencia artificial de código abierto que ha sido rediseñada para ofrecer capacidades agénticas avanzadas, persistencia de datos y una infraestructura colaborativa gratuita e ilimitada. El presentador, *Alejavi Rivera*, destaca cómo esta nueva versión busca superar las limitaciones de los agentes convencionales que se cierran al terminar una tarea.

**Aspectos clave tratados en el video:**

1.  **Instalación y acceso:** (02:19 - 04:47) Se simplificó el proceso con un instalador directo para *Mac*, *Windows* y *Linux*, evitando el uso complejo de terminales. Permite centralizar modelos de *OpenAI*, *Anthropic* y otros.
2.  **Gestión de modelos:** (04:47 - 08:04) Los usuarios pueden vincular diversos proveedores de IA, incluyendo modelos locales o vía *API*, además de configurar claves seguras (*Secrets*) para proteger datos sensibles.
3.  **Interfaz y widgets:** (09:48 - 14:32) La plataforma introduce una interfaz visualmente mejorada que incluye **widgets interactivos** para representar información, superando el uso exclusivo de texto plano.
4.  **Operación 24/7:** (14:32 - 18:04) Se detalla cómo desplegar *OpenClaw* en servidores privados (como un *VPS* de *Hostinger*) para mantener agentes activos permanentemente y sincronizar sesiones entre dispositivos.
5.  **Canales de comunicación:** (18:04 - 20:25) Capacidad de conectar agentes con aplicaciones como *Telegram* o *WhatsApp* para interactuar con ellos de forma cotidiana.
6.  **Memoria y aprendizaje:** (20:25 - 22:27) Implementación de un sistema de "memoria activa" y fases de "sueño" para organizar y priorizar el aprendizaje del agente sobre las interacciones previas.
7.  **Automatización:** (22:27 - 25:26) Introducción de tareas automatizadas, disparadores y flujos de trabajo que permiten delegar responsabilidades complejas al agente en lugar de simples tareas puntuales.

# Instalacion paso a paso

Instalar *OpenClaw 2.0* en *Windows* es un proceso sencillo que no requiere el uso de terminales ni comandos complejos. Sigue estos pasos para configurarlo en tu equipo (02:19 - 03:26):

1.  **Accede a la web oficial:** Dirígete al sitio web de *OpenClaw* (openclaw.ai).
2.  **Descarga el instalador:** Desplázate hacia abajo hasta la sección de descargas y haz clic en el botón **Download** correspondiente a tu sistema operativo (*Windows*).
3.  **Descomprime y ejecuta:** Una vez descargado el archivo, haz doble clic sobre él para descomprimirlo. Luego, abre la aplicación instalada.
4.  **Configuración inicial:** Al abrir la herramienta, aparecerá una ventana emergente de bienvenida (*onboarding*). Haz clic en **Siguiente**.
5.  **Elige la ubicación:** El instalador te preguntará dónde deseas instalarlo (en este ordenador, otro dispositivo o en la nube). Selecciona la opción adecuada para tu caso.
6.  **Finalización:** La herramienta se encargará de instalar todo lo necesario automáticamente. Tras finalizar, serás redirigido al chat principal de la plataforma para comenzar a configurar tus modelos de inteligencia artificial y agentes.
