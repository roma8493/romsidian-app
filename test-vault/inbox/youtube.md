# ¡ADIÓS TAREAS! Genera SKILLS en PILOTO AUTOMÁTICO con Gemini Notebook (GRATIS)

url: https://youtu.be/H_1h8m1tXj8?si=yOLFdBtCxoqUdtzS


## Resumen

Este video presenta un método paso a paso para convertir **Gemini Notebook** en una "fábrica de habilidades" (*skills*) automática, permitiendo a los usuarios crear herramientas profesionales para automatizar tareas en cuestión de minutos (0:00 - 0:37).

**Puntos clave del método:**

1.  **Preparación (0:38 - 2:42):** Configuración inicial de un cuaderno en *Gemini Notebook* subiendo fuentes de aprendizaje y configurando un *prompt* del sistema específico.
2.  **Creación de Skills (2:42 - 14:28):** Joaquín explica cómo investigar temas específicos mediante fuentes, definir los datos del usuario y generar la estructura de la habilidad (*skill*) para luego implementarla en plataformas como *Gemini* o *Claude*.
3.  **Casos de uso reales:**
    *   **Auditoría de contratos:** Análisis de documentos PDF para detectar riesgos y cláusulas (2:42 - 11:00).
    *   **Generación de miniaturas:** Creación de miniaturas optimizadas para *YouTube* usando la IA *Nano Banana 2* (11:00 - 14:28).
    *   **Prompts cinematográficos:** Generación de prompts detallados para video con *Google Omni 1.2* (14:28 - 18:25).

El video también incluye una breve sección promocional sobre *Pollo Cinema* (5:25 - 8:23) y destaca cómo estas habilidades pueden ser reutilizadas infinitamente una vez configuradas.
