## Paso a paso para construir 1er agente 

Crear tu primer agente de IA con *OpenClaw 2.0* es un proceso sencillo que puedes realizar de dos formas principales, dependiendo de si prefieres ejecutarlo localmente en tu ordenador o en un servidor remoto (VPS) para mayor disponibilidad.

### Opción A: Instalación en Local (Recomendada para empezar)

Esta opción es ideal para trastear y experimentar desde casa (12:58):

1.  Visita la web oficial *openclaw.ai* (13:14).
2.  Descarga el instalador correspondiente a tu sistema operativo (*Mac*, *Windows* o *Linux*) (13:18).
3.  Sigue los pasos del asistente de configuración (13:23).
4.  Una vez finalizado, abre la aplicación de escritorio *OpenClaw* para comenzar a configurar tus agentes (13:37).

### Opción B: Instalación en un Servidor VPS (Para ejecución 24/7)

Si necesitas que el agente trabaje solo sin tener el ordenador encendido, usa un *VPS* (6:29):

1.  **Contrata un VPS:** El autor recomienda servicios como *HostGator* (7:42). Elige un plan (como *NVME4* o *NVME8*) y selecciona *Easy Panel* como sistema operativo/panel de administración (7:56 - 8:23).
2.  **Configuración en Easy Panel:** Accede al panel con tu cuenta (8:40).
3.  **Despliegue:** Crea un nuevo proyecto, busca la plantilla de *OpenClaw* (asegúrate de usar la versión estable más reciente encontrada en *GitHub*) y despliégala (8:54 - 9:40).
4.  **Onboarding:** Copia el comando de configuración que proporciona el sistema y ejecútalo en la consola *Bash* de tu *VPS* (9:47 - 10:16).
5.  **Acceso:** Una vez inicializado, el sistema te dará una *URL* del tablero para acceder a tu interfaz web (12:32 - 12:45).

### Pasos posteriores para configurar tu agente:

*   **Definir el Agente:** En la interfaz, puedes crear agentes, asignarles un modelo (por ejemplo, *Open Router* o modelos locales) y configurar sus instrucciones (16:45).
*   **Skills y Herramientas:** Instala *skills* desde *ClawHub* o el taller de habilidades para dar capacidades específicas a tu agente (5:12, 14:27).
*   **Conectividad:** Puedes vincular canales como *Telegram* para interactuar con tu agente desde el móvil (22:38 - 24:07).

Recuerda empezar con una tarea pequeña y comprobable, y medir el ahorro de tiempo real antes de automatizar flujos más complejos (30:05 - 34:59).
