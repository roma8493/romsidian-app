# metodo SOAR

https://youtu.be/eCj68ESyRuY?si=ImgqPVP22jYnT9US

Este video presenta el **método SOAR**, una técnica de aprendizaje diseñada por investigadores de la Universidad de Nebraska-Lincoln, adaptada para ser utilizada con la inteligencia artificial **Gemini Notebook** (0:00-0:30).

El método se divide en cuatro pasos fundamentales para procesar cualquier información (0:41-2:21):

*   **Seleccionar (S):** Reunir las ideas clave y explicaciones necesarias del material de estudio, descartando información irrelevante o repetitiva (0:54-1:07).
*   **Organizar (O):** Estructurar la información mediante herramientas visuales, tablas o esquemas para comparar conceptos y entender procesos (1:08-1:23).
*   **Asociar (A):** Relacionar las nuevas ideas con conocimientos previos y usar comparaciones o ejemplos cotidianos para consolidar la comprensión (1:26-1:46).
*   **Regular (R):** Evaluar el progreso mediante la autoevaluación sin mirar los apuntes, identificando errores y ajustando el repaso en función de las dificultades encontradas (1:47-2:06).

El autor demuestra cómo aplicar este método en la práctica utilizando como ejemplo el estudio de **por qué cambian las estaciones** (3:26-13:25). Además, ofrece una **guía con plantillas gratuitas** para que los espectadores puedan replicar este proceso con cualquier tema, apuntes u oposición (2:31-3:00, 13:26-14:15).
